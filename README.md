# Encryption-Images
## Overview of project
This project allows you to encrypt a text message and output it as a PNG image file. It allows you to both encrypt text and decrypt a message from an image using a key.

## How it works
When you encrypt a message, it will randomly generate a string the same length as the message. It will then loop through the message and encrypt it using XOR. It then detects how many pixels tall the image would be by dividing all the unicode values in the encrypted string by 256 and rounding up to the nearest integer. Then, it places pixels with colour values equal to the unicode value of each character of the encrypted text. If the unicode value is larger than 255, it will put the remainder in the next pixel up, repeating until it is 0. When it decrypts, it will ask you for a file name and a key number (It will also give the options of "list" and "add" the first of which will list the keys in the database and the second of which will allow you to add a key to the database). It will then get the key from the SQLite database once you enter the password you set when you first used the program. If it is correct, it will allow you to continue. Next, it will read the image horizontally and decrypt it using XOR.
